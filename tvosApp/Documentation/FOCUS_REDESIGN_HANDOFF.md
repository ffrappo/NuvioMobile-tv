## Task

User showed a screenshot of the tvOS title details page ("The Devil's Mouth") and said it was a mess. Brief: redesign the details page, then remove the custom focus ugliness app-wide. Final directive: "in doubt do apple default."

## Design direction (binding, from the user)

- Focus is expressed the Apple tvOS way: bright material background, elevation, shadow, slight scale. Never colored strokes, never brand-colored glows, never custom focus rings.
- On focus, interactive rows and buttons become white (dark mode) with dark content. Posters and cards scale up with a stronger shadow. Text fields become white with dark text.
- The user explicitly rejected the purple accent border plus white background combination seen on the details screen.

## Verification and deploy

Build for simulator:

```bash
xcodebuild -project tvosApp/NuvioTV.xcodeproj -scheme NuvioTV \
  -configuration Debug -destination 'generic/platform=tvOS Simulator' \
  CODE_SIGNING_ALLOWED=NO build
```

Deploy to the physical Apple TV (Seminterrato, Apple TV 4th generation, device id 50772D4F-6E52-5646-BEF9-A68B8BF36343):

```bash
./scripts/run-tvos.sh
```

The script regenerates the project with xcodegen, builds for device with the "Nuvio tvOS Development" profile, installs, and launches. Round 1 is already on the device. Round 2 is not deployed yet.
